# Code • Connect • Create - Logo Collection

This directory contains the official logos for the **"Code • Connect • Create"** youth development program, focused on apps, IoT, and robotics education.

## Available Logo Variations

### 1. Minimalist Logo (`logo_minimalist.svg`)
- **Best for**: Simple applications, letterheads, minimal designs
- **Dimensions**: 400×120px
- **Style**: Clean text with gradient, minimal decorative elements
- **Use case**: When you need a clean, professional look

### 2. Logo with Icons (`logo_with_icons.svg`)
- **Best for**: Presentations, educational materials, program brochures
- **Dimensions**: 500×150px
- **Style**: Text with representative icons for Code, Connect, Create
- **Use case**: When you want to emphasize the three core concepts

### 3. Badge Logo (`logo_badge.svg`)
- **Best for**: Social media profiles, certificates, achievement badges
- **Dimensions**: 300×300px (square)
- **Style**: Circular badge design with triangular C arrangement
- **Use case**: Social media, awards, circular/badge applications

### 4. Horizontal Logo (`logo_horizontal.svg`)
- **Best for**: Website headers, banners, wide format applications
- **Dimensions**: 600×80px
- **Style**: Horizontal layout with tech decorative elements
- **Use case**: Headers, banners, business cards

### 5. Tech Style Logo (`logo_tech_style.svg`)
- **Best for**: Technical documentation, modern presentations
- **Dimensions**: 450×200px
- **Style**: Circuit board pattern with connected elements
- **Use case**: Technical contexts, modern tech aesthetic

## Color Palette

The logos use a consistent color scheme:

- **Primary Blue**: `#4F46E5` (Code/Programming)
- **Purple**: `#7C3AED` (Connect/IoT)
- **Pink**: `#EC4899` (Create/Innovation)
- **Accent Orange**: `#F59E0B` (Energy/Youth)
- **Gray Text**: `#6B7280` (Subtitles)
- **Light Gray**: `#9CA3AF` (Supporting text)

## Usage Guidelines

### Do's ✅
- Use the original SVG files for best quality
- Maintain aspect ratios when resizing
- Use on backgrounds that provide sufficient contrast
- Choose the appropriate logo variation for your use case

### Don'ts ❌
- Don't modify the colors without permission
- Don't distort or stretch the logos
- Don't add effects that compromise readability
- Don't use on backgrounds that reduce visibility

## File Formats

All logos are provided in SVG format for:
- **Scalability**: Perfect quality at any size
- **Small file size**: Efficient for web use
- **Editability**: Can be modified with vector graphics software
- **Print quality**: High resolution for print materials

## Program Focus

The "Code • Connect • Create" program emphasizes:

- **📱 Apps**: Mobile application development using MIT App Inventor
- **🔗 IoT**: Internet of Things projects with ESP32 microcontrollers
- **🤖 Robotics**: Interactive hardware programming and automation
- **👥 Youth**: Designed for students aged 14-18
- **🎯 Hands-on**: Project-based learning approach
