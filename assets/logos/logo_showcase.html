About the Program

"Code • Connect • Create" is a comprehensive youth development program focused on:

  • 📱 Apps: Mobile application development using MIT App Inventor
  • 🔗 IoT: Internet of Things projects with ESP32 microcontrollers
  • 🤖 Robotics: Interactive hardware programming and automation

The program is designed for students aged 14-18 and emphasizes hands-on, project-based learning through 30 interactive sessions.
