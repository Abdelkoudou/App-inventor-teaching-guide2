# Logo Assets for "Code • Connect • Create"

This folder contains the vectorized logo files for the "Code • Connect • Create" program.

## Logo Files

### `logo.svg` - Main Logo
- **Dimensions**: 400x120px
- **Usage**: Primary logo for documentation, presentations, and marketing materials
- **Features**: 
  - Three distinct sections representing CODE, CONNECT, CREATE
  - Visual elements for apps (mobile icon), IoT (network nodes, ESP32), and robotics (gears, sensors)
  - Modern gradient colors optimized for youth appeal
  - Fully scalable vector format

### `logo-compact.svg` - Compact Logo  
- **Dimensions**: 300x60px
- **Usage**: Header logo, compact spaces, inline usage
- **Features**: 
  - Streamlined version of the main logo
  - Maintains key visual elements in reduced space
  - Ideal for headers and smaller applications

### `logo-dark.svg` - Dark Theme Logo
- **Dimensions**: 400x120px  
- **Usage**: For dark backgrounds and dark theme applications
- **Features**: 
  - Optimized colors for dark backgrounds
  - Enhanced brightness and contrast for visibility
  - Same design elements as main logo

## Design Elements

### Color Scheme
- **CODE (Purple/Indigo)**: `#4F46E5` to `#7C3AED` - Represents programming and logic
- **CONNECT (Green/Teal)**: `#059669` to `#0D9488` - Represents connectivity and networking  
- **CREATE (Red/Orange)**: `#DC2626` to `#EA580C` - Represents creativity and innovation

### Symbolism
- **CODE**: Brackets, binary patterns, mobile app icon
- **CONNECT**: Network nodes, wireless signals, ESP32 microcontroller
- **CREATE**: Lightbulb (creativity), gear (engineering), robot (IoT/robotics)

## Program Focus Areas

The logo represents the three core pillars of the program:
1. **CODE**: App development with MIT App Inventor
2. **CONNECT**: IoT connectivity with ESP32 and wireless technologies  
3. **CREATE**: Robotics integration and creative problem-solving

## Usage Guidelines

- Always maintain aspect ratio when scaling
- Ensure adequate white space around the logo
- Use `logo.svg` on light backgrounds for optimal visibility
- Use `logo-dark.svg` for dark backgrounds and dark theme applications
- Use `logo-compact.svg` for headers and space-constrained layouts
- SVG format ensures crisp display at any size
- Minimum size recommendation: 150px width for readability
